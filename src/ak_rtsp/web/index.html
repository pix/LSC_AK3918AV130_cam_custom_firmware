          How to install the certificate
          

            
Windows — open the file, Install Certificate, Local Machine, place it in “Trusted Root Certification Authorities”.

            
macOS — open the file to add it to Keychain Access, double-click it, and set Trust to “Always Trust”.

            
iPhone / iPad — download it in Safari, install it in Settings › Profile Downloaded, then enable it in Settings › General › About › Certificate Trust Settings.

            
Android — Settings › Security › Encryption & credentials › Install a certificate › CA certificate.

            
Firefox — Settings › Privacy & Security › Certificates › View Certificates › Authorities › Import, and trust it for websites.

            
Chrome / Edge on Linux — Settings › Privacy and security › Security › Manage certificates › Import (trusted for websites).
